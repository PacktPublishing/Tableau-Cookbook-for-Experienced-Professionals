## What is this book about?
Advance your Tableau knowledge beyond the basics, streamline dashboard performance, tackle advanced geospatial challenges, and unlock API potential while fortifying your corporate data infrastructure with proven best practices.

This book covers the following exciting features:
* Build advanced, high-performing Tableau data models and tables
* Tackle data complexities with LOD expressions and table calculations
* Leverage zone visibility to build interactive and user-friendly dashboards
* Optimize workbook performance for improved user experience
* Analyze geospatial data with map layers, shapefiles, and spatial joins
* Develop a deeper understanding of Tableau's REST API capabilities
* Use Tableau’s order of operations to troubleshoot calculations
* Adopt industry-standard best practices to secure corporate data assets

**Following is what you need for this book:**
This cookbook is for Tableau users and developers, BI administrators, and data analysts ready to explore advanced techniques and deepen their expertise. To make the most of this book, you should either have intermediate to advanced experience with Tableau Desktop and its core functionalities or bring strong proficiency from other BI platforms. If you’re coming from another BI background, this book will prove invaluable as it demonstrates Tableau’s real-world applications. Familiarity with products such as Tableau Cloud and Tableau Server is beneficial, but not a prerequisite for using this book.

With the following software and hardware list you can run all code files present in the book (Chapter 1-10).
